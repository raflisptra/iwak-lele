Topologi

BASELINE langsung: ESP32 MQTT/HTTP/WS → Wi-Fi AP/Router → Server Node.js + Mosquitto + SQLite → SiLele
PENGUJIAN impairment: ESP32 MQTT/HTTP/WS → Wi-Fi AP/Router → Raspberry Pi (tc/netem) → Server → SiLele
Catatan: alamat IP disesuaikan dengan topologi lab. Data QoS perlu berasal dari pengukuran PCAP.

Contoh perintah tc/netem sesuai subbab 6.10 (jalankan di Linux Gateway)

Contoh di bawah menunjukkan satu nilai untuk setiap jenis impairment. Ulangi sesi pengujian dengan seluruh nilai yang tercantum pada proposal. Ganti eth0 jika nama interface gateway berbeda. Terapkan satu jenis impairment saja per sesi.

# Baseline: hapus impairment sebelum sesi dimulai
tc qdisc del dev eth0 root 2>/dev/null

# Latency: ulangi +100 ms sampai +1000 ms
tc qdisc replace dev eth0 root netem delay 100ms

# Packet loss: ulangi 10% sampai 100%
tc qdisc replace dev eth0 root netem loss 10%

# Bandwidth: ulangi 1024, 512, 128, 64, 32, 16, 8, 4, 2, dan 1 Kbps
tc qdisc replace dev eth0 root tbf rate 1024kbit burst 32kbit latency 400ms

# Jalankan lagi sebelum beralih ke skenario berikutnya
tc qdisc del dev eth0 root
